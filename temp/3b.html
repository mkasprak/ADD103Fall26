Overview

Tables organize tabular data in grids of rows and columns. In this lesson, we cover **HTML Tables** in depth, focusing on building accessible data grids using standard semantic tags, cell spanning attributes, and custom cell layouts.

You will learn how to structure tables using the <thead> and <tbody> tags, write column-scoped (scope="col") headers, use the colspan attribute to merge cells across multiple columns, and embed assets like images inside individual table cells.

Assignment Directions

  1. Repository Setup: Open your local course folder inside VS Code and navigate to the week_03 directory. Create a new subfolder named week_03b.
  2. HTML File Creation: Create an index.html file within your week_03b folder. Include the standard HTML5 boilerplate markup (DOCTYPE, head, body).
  3. CSS File Link: Create a style.css file in the same directory and link it inside the <head> of your HTML file.
  4. Table Structure: Build a calendar or scheduled layout table containing:
    • A <thead> section with <th scope="col"> header elements for days of the week or time slots.
    • A <tbody> containing at least 4 rows of data.
    • At least one merged cell using the colspan attribute to span across multiple columns.
    • At least one embedded image asset placed neatly inside a table data cell (<td>).
  5. CSS Styling: In your style.css file, apply borders using border-collapse: collapse;, custom cell padding, background colors, and header typography.
  6. Publish & Submit: Commit and push your changes to your GitHub repository. Ensure your GitHub Pages site updates, and submit your live GitHub Pages URL in Canvas.
